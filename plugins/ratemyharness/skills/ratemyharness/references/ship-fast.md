# Ship-fast local-prototype review

Use this only for the `local-prototype` degree. It reduces breadth, never safety boundaries.

## Minimum pass

1. Trace one representative task from input to verified terminal outcome.
2. Inspect the loop's independent step, tool, time, token, and cost limits.
3. Inject one inert tool failure and verify truthful failure or recovery.
4. Verify cancellation is observed and no further synthetic effect occurs.
5. Inspect the highest-authority tool path, approval point, and untrusted inputs.
6. Check session isolation when any state persists.
7. Compare the harness to the simplest plausible baseline or label value unverified.

Stop immediately on a fixed veto. Do not spend a quick review on style while an unsafe path remains.

## Compact output

```text
Decision:
Maximum safe target:
Why, in one sentence:

Blocker or largest unknown:
Fastest safe fix:
Acceptance test:
Next review depth needed:
```

A quick pass authorizes only local-prototype use. It is not evidence for team sharing, public release, privileged production, or high-stakes use.
